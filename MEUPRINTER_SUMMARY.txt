🎯 COMO USAR
───────────────────────────────────────────────────────────────────

1️⃣  COMPILAR
    $ chmod +x build_meuprinter_macos.sh
    $ ./build_meuprinter_macos.sh

2️⃣  EXECUTAR
    $ ./build/arm64/src/OrcaSlicer.app/Contents/MacOS/OrcaSlicer

3️⃣  USAR MEUPRINTER
    ✓ Abrir OrcaSlicer
    ✓ Selecionar "MeuPrinter" em Impressora
    ✓ Escolher bico (0.2, 0.4, 0.6, 0.8mm)
    ✓ Escolher filamento (PLA, PETG, ABS)
    ✓ Escolher processo (Fine, Standard, Draft)

4️⃣  USAR MISTURA DE CORES (após integração CMakeLists.txt)
    ✓ Clicar na aba "Mistura de Cores"
    ✓ Clicar "Add Mix" para nova mistura
    ✓ Configurar filamentos e torre de purga
    ✓ Salvar como preset

───────────────────────────────────────────────────────────────────
📊 ESPECIFICAÇÕES MEUPRINTER
───────────────────────────────────────────────────────────────────

BICOS DISPONÍVEIS:
├─ 0.2mm → Detalhes muito finos
├─ 0.4mm → Padrão (recomendado)
├─ 0.6mm → Impressão mais rápida
└─ 0.8mm → Objetos grandes

FILAMENTOS COMPATÍVEIS:
├─ PLA (todos os bicos)
├─ PETG (bicos ≥ 0.4mm)
└─ ABS (todos os bicos)

PROCESSOS:
├─ Fine 0.12mm    → Bicos 0.2, 0.4mm
├─ Standard 0.20mm → Todos
└─ Draft 0.28mm    → Bicos ≥ 0.4mm
